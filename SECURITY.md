# Security and privacy

This plugin reads a founder's own records (notes, CRM exports, repositories, websites) to write about them. That makes two things matter more than usual.

**Reporting a problem.** If you find a way the skill could leak a credential, a private path, a figure or a personal detail into a public output, or an instruction that would lead an agent to do so, please report it privately rather than in a public issue: open a security advisory on the repository ("Security" tab, "Report a vulnerability"), or email the maintainer address shown on the organisation's GitHub profile. You will get an acknowledgement within a few days.

**What the skill promises.** Read-only access to sources; a credential filter before any file is read; figures and third-party names kept private unless the founder clears them; nothing sent, posted or published. See `PRIVACY.md` and the ground rules in `skills/founder-of-the-year/references/source-adapters.md`. A change that weakens any of those is a security issue, not a style choice.
